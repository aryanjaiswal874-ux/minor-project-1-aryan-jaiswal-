# Bank Transaction Analysis Dashboard

A simple and interactive dashboard for analyzing bank transactions using Streamlit.

---

## Overview

This project allows users to upload transaction data and explore it through filters, metrics, and visualizations. It helps in understanding spending patterns and identifying unusual transactions.

---

## Features

* Upload CSV file
* Filter by date and transaction type
* View key metrics (total, average, maximum, count)
* Daily transaction trend
* Credit vs debit analysis
* Monthly summary
* Detect high-value transactions
* Download filtered data

---

## Tech Stack

Python, Streamlit, Pandas, Plotly

---

## Dataset

Required columns:

TransactionID, Date, Amount, Type

---
